# NyayaSetu — Free Online Deployment Guide (₹0/month)

1. **GitHub Pages (Free Frontend Hosting)**:
   - Create a new public GitHub repository and upload `index.html`.
   - Go to **Settings → Pages → Deploy from branch (`main` / root)** to get your live `https://<username>.github.io/<repo>/` link.
2. **Supabase (Free Production SQL Database)**:
   - Create a free project at supabase.com and run `schema.sql` in the SQL Editor.
   - Open **Admin Control** in the app (`admin@nyayasetu.in` / `admin123`) and paste your Supabase Project URL and `anon` key.
3. **Free Payment Collection (UPI / Bank)**:
   - In **Admin Control → Free Payment Gateway & Payout Account**, enter your Merchant UPI VPA and Bank Account/IFSC to enable live `upi://pay` links.
